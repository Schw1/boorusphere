**Test build** of automatic backups and random order (branch `autobackup-random`). Not merged into `main` yet. Includes native Monbooru support from `main`.

## New
- **Automatic backup:** Settings → Backup and Restore. Runs when the app is opened (daily or weekly) and keeps the newest 1/3/5/10 automatic backups. Manual backups are never deleted. Backups are in the Files app under "On My iPhone → Boorusphere → backups".
- **Random order:** new "random" toggle next to the rating filter in the search bar, applied from the next search. Works per booru type (Danbooru, Moebooru, e621, Gelbooru, Safebooru, Szurubooru, Philomena, Shimmie, Monbooru).

## Installation
Install `boorusphere-unsigned.ipa` with Sideloadly over the existing app (same Apple ID, don't delete the app first). To go back, install the latest regular release the same way.
